# AMORA – Elegance & Style 🛍️

A modern and responsive e-commerce website built with React.js and Tailwind CSS. AMORA provides a clean, elegant, and user-friendly shopping experience with product browsing, cart management, checkout, and admin functionality.

## 🚀 Features

- Responsive and modern e-commerce UI
- Product categories and product search
- Featured products section
- Product details page
- Add to Cart functionality
- Cart quantity management
- Wishlist functionality
- Checkout form
- Order management
- Admin dashboard
- Product management
- Responsive navigation and footer
- MongoDB database integration
- REST API with Node.js and Express.js

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
